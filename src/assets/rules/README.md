# Reglamento local

Coloca aquí el PDF del reglamento con el nombre `rules-<idioma>.pdf` (por ejemplo `rules-es.pdf` para español).
Si el archivo existe, el menú principal muestra la entrada "Reglas (PDF)" que lo abre en una pestaña nueva.

Los PDF están en `.gitignore`: el reglamento tiene copyright de Cephalofair Games y no debe subirse al repositorio.
